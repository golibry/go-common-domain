# go-common-domain

Ubiquitous domain language and concepts to be used in Go projects

## Examples

See [`_examples`](./_examples) and [`_examples/README.md`](./_examples/README.md) for standalone
programs covering construction, normalization, JSON, database scan/reconstitution behavior, and finance
helpers such as `Money` and `PercentageRate`.

Run all library tests:

```
go test ./...
```
